# 운동기 (Gymcall)

아침 운동 약속이 있는 친구들이 "ㅇㄷㄱ?(운동 가?)" 카톡과 모닝콜 대신, 알람 해제를 곧 참가 선언으로 만들고 일어나지 않은 친구를 친구 목소리와 찌르기로 깨우는 웹 앱.

**Demo:** [gymcall.json-server.win](https://gymcall.json-server.win) (홈랩 K3s 배포, Chrome 권장)

---

## 1. 문제 정의

### 대상 사용자
평일 아침 정해진 시간에 친구와 같이 운동하러 가는 사람과 그 친구 그룹. 기상 스터디, 아침 러닝 크루처럼 "같은 시간에 일어나 같이 나가기로 한" 모든 소규모 모임.

### 문제 상황
- 팀원(장수)은 평일 대부분 08시에 일어나 친구와 함께 운동을 간다.
- 누군가 늦잠을 자거나 가기 싫어 미루면(상황), 다른 친구가 카톡 개인 채팅으로 "ㅇㄷㄱ?"를 보내고 답이 없으면 전화까지 걸어 깨워야 한다(불편).
- 깨우는 사람은 매번 같은 메시지를 사람마다 따로 보내야 하고, 누가 일어났는지 한눈에 알 수 없다. 깨워지는 사람은 혼자 끄는 개인 알람이라 약속의 무게를 느끼지 못한다.

### 기존 방식과 한계
| 기존 방식 | 한계 |
|---|---|
| 각자 휴대폰 알람 | 혼자 끄면 끝. 친구는 내가 일어났는지 모른다 |
| 카톡 "ㅇㄷㄱ?" | 사람마다 따로 보내야 하고, 답을 기다려야 참가 여부를 안다 |
| 전화로 깨우기 | 깨우는 사람이 시간을 맞춰 직접 걸어야 하고, 여러 명이면 반복해야 한다 |
| 습관 앱, 기상 인증 앱 | 혼자 쓰는 기록이 중심이라 "같이 나가는 약속"을 다루지 않는다 |

### 근거
팀원과 운동 친구의 1:1 카카오톡 대화 중 **최근 3개월(2026-08-14 ~ 11-14) 오전 6~11시 메시지 340줄**을 AI 에이전트(Kiro)가 직접 읽고 날짜별로 분류했다. 키워드 정규식으로 셌을 때는 2년 넘는 기간에서 22일만 잡혔다. "동운 기?", "덩운..", "웅덩?", "어대고"처럼 매번 다르게 쓴 말이 빠졌기 때문이다. 개인정보 보호를 위해 원문과 이름은 레포에 넣지 않고 숫자만 적는다.

| 지표 (3개월) | 값 |
|---|---|
| 아침에 "운동 가?"를 물은 날 | **28일** (평일 24일, 토요일 4일) |
| 그중 10분 넘게 답이 없거나 그날 아침 끝내 답이 없던 날 | **16일 (57%)**. 10분 이상 10일, 무응답 6일 |
| 늦게 온 답장의 대기 시간 | 12분 ~ 126분 |
| "늦잠", "이제 일어남"처럼 늦잠을 직접 밝힌 날 | 5일 |
| 깨우기를 먼저 물은 사람 | 두 사람이 번갈아. 한쪽만의 문제가 아니다 |
| "어디야(ㅇㄷ, 어대고, 어딘고)"로 위치를 물은 날 | 5일 |
| 같은 장소(헬스장 앞 카페)에서 만나자고 맞춘 날 | 5일 |
| "갈 때 전화 주세요"처럼 깨워 달라고 부탁한 날 | 1일 |
| 결국 같이 못 간 날의 이유 | 출근·출장·회의·수업 5일, 몸살·복통 3일, 피곤 1일 |

- 운동 가냐고 물은 날의 절반 넘게(57%), 묻는 쪽은 10분 이상 답을 기다리거나 끝내 못 받는다. 기다리는 동안 집에서 나갈지 말지 정하지 못한다.
- 답을 늦게 한 날은 대부분 이미 늦잠을 잔 날이었다. 알람이 혼자 끄는 것이라 친구가 깨울 방법이 카톡과 전화뿐이다.
- 위치를 묻고 만날 곳을 맞추는 대화가 따로 생긴다.
- 분류 기준: 철자와 상관없이 "오늘 운동 가?"를 묻는 메시지면 셌다. 이모티콘만 보낸 날과 점심 약속은 뺐다. 오전 11시 전에 상대 메시지가 없으면 무응답으로 봤다. 전화는 카톡 내보내기에 남지 않아 세지 못했다.

### 목표
1. 알람을 끄는 동작 하나로 "간다 / 못 간다"가 그룹 전체에 1초 안에 공유되게 한다.
2. 일어나지 않은 친구는 카톡과 전화 대신 앱 안에서 친구 목소리 클립과 찌르기로 깨운다.
3. 매일 보는 화면에는 "오늘 누가 일어났나"만 남겨 아침의 인지 부하를 줄인다.

## 2. 핵심 기능

| 기능 | 해결하는 불편 | 코드 위치 |
|---|---|---|
| 그룹과 초대(코드, QR, 링크) | 친구를 한 번에 모으기 | `src/app/api/groups/route.ts`, `src/app/api/groups/join/route.ts`, `src/components/group-settings.tsx` |
| 계정 로그인 (닉네임 + 비밀번호, 쿠키 세션) | 내 응답을 남이 대신 누르지 못하게 하기 | `src/lib/auth.ts`, `src/app/api/auth/` |
| 그룹 알람과 응답 = 알람 해제 | 개인 알람은 혼자 끄면 끝. 끄는 동작이 곧 참가 선언 | `src/lib/alarm.ts`, `src/app/api/groups/[id]/respond/route.ts` |
| 실시간 현황 (SSE) | "ㅇㄷㄱ?"에 답을 기다리지 않고 1초 안에 모두가 앎 | `src/lib/events.ts`, `src/app/api/groups/[id]/events/route.ts` |
| 멤버 카드 그리드와 깨우기 클립 | 내 얼굴·목소리 10초 클립이 내 카드에서 반복. 알람이 울리는데 응답하지 않은 친구 화면에서는 여러 친구의 클립 소리가 한꺼번에 켜짐 | `src/components/member-card.tsx`, `src/components/clip-recorder.tsx`, `src/lib/clip.ts` |
| 찌르기 (여러 명, 연타 배지) | 전화 대신. 카드를 골라 누르면 받은 친구 화면이 세게 출렁임 | `src/app/api/groups/[id]/poke/route.ts`, `src/components/group-view.tsx`, `src/app/globals.css` |
| 무응답 자동 확정과 가상 벌금(선택) | 약속의 무게. 알람 10분 뒤 무응답이면 불참 확정, 포인트 차감(실제 결제 없음) | `src/lib/attendance.ts`, `src/lib/penalty.ts`, `src/lib/penalty-store.ts` |
| 모임 설정 화면 | 가끔 바꾸는 값(시간, 벌금, 장소, 초대)을 매일 보는 화면에서 분리 | `src/app/g/[id]/settings/page.tsx`, `src/components/group-settings.tsx` |

## 3. 사용 시나리오

1. 장수가 로그인 후 "새벽조" 그룹을 만들고, 설정 화면의 QR을 친구 둘에게 보낸다. 친구들은 QR을 찍어 가입하고 그룹에 들어온다.
2. 설정에서 모임 시간을 08:00, 벌금을 10P로 정한다. 각자 내 카드를 눌러 "야 일어나라" 10초 클립을 찍어 둔다.
3. 전날 밤 각자 그룹 화면에서 "알람 켜기"를 누르고 탭을 열어 둔다.
4. 08:00, 모두의 화면에 잔잔한 파장이 퍼지고, 아직 응답하지 않은 사람의 화면에서는 친구들의 클립 소리가 함께 울린다.
5. 장수가 "간다"를 누르면 소리가 멈추고, 친구들 화면의 장수 카드가 1초 안에 "간다"로 바뀐다.
6. 응답이 없는 친구의 카드를 골라 "찌르기"를 연타한다. 친구 화면이 세게 출렁이고, 연타가 쌓일수록 배지가 화려해진다.
7. 08:10까지 응답이 없으면 무응답으로 확정되고 10P가 깎인다. 모임 장소를 정해 두었다면 위치를 켠 친구가 장소에 도착하는 순간 "도착"으로 자동 출석된다.

## 4. 기대 효과

아래는 측정값이 아니라 설계 목표다. "지금" 칸은 위 근거의 카톡 집계 값이다.

| 항목 | 지금 (카톡·전화) | 운동기 목표 |
|---|---|---|
| 아침 확인 메시지 | 3개월 동안 28일, 날마다 직접 물어봄 | 0개 (알람 해제가 곧 공유) |
| 모두의 참가 여부를 아는 시점 | 물은 날의 57%는 10분 넘게 기다리거나 답 없음 (최대 126분) | 응답 후 1초 안 (SSE) |
| 늦잠 친구 깨우기 | 전화 1통 이상, 시간 맞춰 직접 | 카드 고르고 찌르기 1번 |
| 불참 확정 | 서로 눈치 | 알람 10분 뒤 자동 |

## 5. 차별점

- **알람 해제 = 참가 선언.** 일반 알람 앱은 끄면 끝이지만, 운동기는 끄는 동작이 곧 그룹에 보내는 응답이다. 따로 메시지를 보낼 단계가 없다.
- **친구 목소리가 알람음.** 미리 찍어 둔 친구 클립이 내 알람으로 울리고, 응답하지 않으면 여러 친구 목소리가 한꺼번에 울린다.
- **깨우는 행동이 앱 안에 있다.** 카톡과 전화로 하던 깨우기를 찌르기 한 번으로 바꿨고, 여러 명을 동시에 찌를 수 있다.
- **매일 화면의 정보를 줄였다.** 그룹 화면은 카드 그리드와 버튼 하나뿐이고, 시간·벌금·장소·초대는 설정 화면에 모았다.
- **LLM 없이 결정론 코드만.** 알람 판정, 출석 집계, 벌금, 자동 출석 판정은 모두 테스트된 순수 함수다(`src/lib/`, `tests/`).

### 한계
- 웹 앱이라 **탭이 열려 있어야** 알람이 울린다. 소리 재생 허락을 위해 "알람 켜기"를 한 번 눌러야 한다(Chrome 자동 재생 정책).
- 카메라, 마이크, 위치는 HTTPS 또는 localhost에서만 동작한다.
- 데모는 Chrome 기준이다. 브라우저마다 녹화 형식(webm, mp4)이 달라 다른 브라우저끼리 재생이 보장되지 않는다.
- 벌금은 가상 포인트이며 실제 결제는 없다.
- 위치는 DB에 저장하지 않고 서버 메모리에만 둔다. 서버가 하나(replicas 1)라는 전제다.
- 비밀번호 재설정과 로그인 시도 제한은 없다.

## 6. 설치와 실행

Node.js 24, pnpm 12 기준. 외부 API 키가 필요 없다. DB는 SQLite 파일(`data/app.db`)이다.

```bash
# 1. 의존성 설치 (Prisma 클라이언트 자동 생성)
pnpm install

# 2. DB 만들기
pnpm db:migrate

# 3. 실행 (시간대는 서울 기준)
TZ=Asia/Seoul pnpm dev
# http://localhost:3000
```

컨테이너로 실행:

```bash
docker build -t gymcall .
docker run -p 3000:3000 -v gymcall-data:/app/data -e TZ=Asia/Seoul gymcall
```

배포: GitHub Actions가 `main` push마다 GHCR에 이미지를 올리고(`.github/workflows/image.yml`), 홈랩 ArgoCD가 `infra/k8s/overlays/prod`를 동기화한다. 배포 규칙은 `.kiro/steering/deploy.md`.

시연 팁: 설정 화면의 "1분 뒤로 맞추기"로 알람을 바로 울릴 수 있다. 두 사람은 일반 창과 시크릿 창(또는 다른 브라우저)으로 각각 로그인한다.
