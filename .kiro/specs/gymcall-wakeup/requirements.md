# 요구사항: 실시간 깨우기 (운동기 핵심 기능 확장)

본 기능은 `.kiro/specs/gymcall/`의 깨우기 클립(R4)을 보완한다. 클립은 미리 남기는 비동기 방식이고, 이 기능은 지금 바로 상대의 알람을 울리는 실시간 방식이다.

## 소개
멤버가 버튼 하나로 다른 멤버의 폰에서 알람을 울린다. 받은 멤버는 "일어났다"를 눌러야 알람이 꺼진다. 먼저 SSE로 만들고(1단계), 시간이 있으면 웹 푸시로 탭이 닫혀 있어도 알린다(2단계).

## 용어
- 깨우기 호출: 멤버 A가 멤버 B에게 보내는 즉시 알람 신호.
- 일어남: 호출을 받은 멤버가 "일어났다"를 눌러 기록되는 새 상태. "간다"와 별개다.
- 호출 만료: 호출 후 `WAKE_CALL_MAX_MINUTES`(5분)가 지나면 울림이 끝난다.

## 요구사항

### R11. 깨우기 호출 보내기
**사용자 스토리:** 멤버로서, 일어나지 않는 친구의 폰을 지금 울리고 싶다.

인수 조건
1. 멤버 목록의 다른 멤버 옆에 "지금 깨우기" 버튼이 있다. 자기 자신에게는 없다.
2. 누르면 호출이 만들어지고 상대에게 즉시 전달된다.
3. 보낸 멤버 화면에 "호출 중"이 보인다.
4. 호출 횟수 제한은 두지 않는다. 같은 사람을 여러 번 호출할 수 있다.
5. 호출은 알람 시각과 무관하게 언제든 보낼 수 있다.

### R12. 받은 폰이 울림
**사용자 스토리:** 호출을 받은 멤버로서, 알람이 울려 잠에서 깨고 싶다.

인수 조건
1. 탭이 열려 있고 "알람 켜기"를 누른 상태에서 호출이 오면 1초 안에 소리가 반복 재생된다.
2. 화면에 보낸 멤버 닉네임과 "일어났다" 버튼이 전체 화면으로 보인다.
3. 보낸 멤버가 보낸 미사용 클립이 있으면 그것을 재생하고, 없으면 기본 알람음을 쓴다. 영상은 전체 화면, 음성은 소리만이다. (R3, R4와 같은 재생 규칙)
4. "일어났다"를 누르기 전에는 끌 수 없다. 화면에 다른 닫기 동작을 두지 않는다.
5. 호출 후 5분이 지나면 자동으로 멈춘다.
6. 이미 울리는 중에 같은 멤버에게 호출이 또 와도 소리는 하나만 울린다.
7. 탭을 새로 열거나 새로고침했을 때 만료 전 호출이 남아 있으면 다시 울린다.
8. 한계: 1단계에서는 탭이 닫히면 울리지 않는다. 화면에 안내한다. 알람(R3.6)과 같은 한계다.

### R13. 일어났다 응답
**사용자 스토리:** 호출을 보낸 멤버로서, 상대가 일어났는지 알고 싶다.

인수 조건
1. "일어났다"를 누르면 소리가 멈추고 그 멤버에게 온 만료 전 호출이 모두 닫힌다.
2. 보낸 멤버 화면에 "OO 일어남"이 1초 안에 보인다.
3. 5분 안에 누르지 않으면 보낸 멤버 화면에 "응답 없음"이 보인다.
4. 그룹 화면 멤버 목록에 그날 "일어남" 표시가 남는다. 이 표시는 "간다 / 못 간다" 응답과 따로 있다.
5. "일어남"은 불참 확정과 포인트 차감에 영향을 주지 않는다.

### R14. 웹 푸시 (2단계, 시간이 있을 때)
**사용자 스토리:** 받는 멤버로서, 탭을 닫아도 호출을 받고 싶다.

인수 조건
1. 멤버는 "알림 받기"를 눌러 푸시 알림을 허용한다. 거부하면 SSE 방식만 쓴다.
2. 호출이 오면 탭이 닫혀 있어도 푸시 알림이 온다.
3. 알림을 누르면 앱이 열리고 R12의 반복 알람이 시작된다.
4. 푸시 알림 자체는 소리를 반복하지 않는다. 화면에 이 한계를 안내한다.
5. 아이폰은 홈 화면에 추가해야 받을 수 있다. 화면에 안내한다.
6. 탭이 열려 있으면 푸시 대신 SSE로 울린다. 중복 알림을 만들지 않는다.

## 비기능 요구사항
- N11. 유료 API를 쓰지 않는다. 푸시 키(VAPID)는 직접 생성하고 `.env`에만 둔다. 커밋하지 않는다. (본 앱 N1, N4와 같은 기준)
- N12. 푸시 구독 정보는 멤버 ID에 묶어 DB에 저장한다. 위치와 달리 저장이 필요하다.
- N13. 데모는 Chrome에서 한다.

## 범위 밖
- 호출 횟수 제한, 차단, 방해 금지 시간
- 전화 연결, 반복 푸시 재전송
- 호출 이력 화면

## 열린 질문 (임시값)
- 호출 만료: 5분. 상수 `WAKE_CALL_MAX_MINUTES` 한 곳에 둔다.
- 호출에 보낸 멤버의 클립을 쓸지, 항상 기본 알람음을 쓸지: 클립 우선(R12.3). 데모 뒤에 바꿀 수 있다.
- 제한이 없어서 같은 사람에게 무한 호출이 가능하다. 그룹 안 친구끼리 쓰는 앱이라 허용한다. README 한계에 적는다.
