# 요구사항: 모임 지도와 자동 출석 (운동기 부가 기능)

본 기능은 `.kiro/specs/gymcall/`의 부가 기능이다. 핵심 흐름(알람, 응답, 클립, 포인트)은 바꾸지 않는다.

## 소개
알람에 일어난 멤버들이 한곳에 모여 함께 운동하러 간다. 모일 때 카톡으로 "ㅇㄷ?"(어디야?)를 묻는 일이 잦다. 알람 이후 정해진 시간 동안 멤버 위치를 지도에 보여 주고, 모임 장소 근처에 오면 자동으로 "간다"로 기록한다.

## 용어
- 모임 장소: 그룹이 정한 한 곳의 좌표와 반경. 그룹당 하나다.
- 공유 시간대: 알람 시각부터 `SHARE_WINDOW_MINUTES`(임시 120분) 동안.
- 위치 공유: 멤버가 직접 켠 동안만 서버로 현재 위치를 보내는 동작.
- 자동 출석: 공유 시간대에 모임 장소 반경 안에 들어온 멤버를 "간다"로 기록하는 일.

## 요구사항

### R7. 위치 공유 켜기
**사용자 스토리:** 멤버로서, 내 위치를 보낼지 내가 정하고 싶다.

인수 조건
1. 그룹 화면에 "위치 공유" 스위치가 있고 기본은 꺼짐이다.
2. 스위치를 켜면 브라우저가 위치 권한을 묻는다. 거부하면 이유와 해결 방법을 보이고 스위치는 꺼진 채로 둔다.
3. 공유 시간대가 아니면 스위치를 켜도 위치를 보내지 않고 "알람 후 N분 동안만 공유돼요"를 보인다.
4. 공유 시간대가 끝나면 보내기가 자동으로 멈추고 스위치가 꺼진다.
5. 스위치를 끄거나 탭을 닫으면 그 멤버의 위치가 지도에서 사라진다.

### R8. 모임 지도 탭
**사용자 스토리:** 멤버로서, 친구들이 지금 어디쯤인지 지도로 보고 싶다.

인수 조건
1. 그룹 화면에 "지도" 탭이 있다.
2. 위치를 공유 중인 멤버가 닉네임과 함께 지도에 찍힌다. 마지막 갱신이 60초를 넘으면 흐리게 보인다.
3. 모임 장소가 있으면 반경 원과 함께 보인다.
4. 위치가 바뀌면 같은 그룹의 열린 화면에 5초 안에 반영된다.
5. 공유하지 않는 멤버는 목록에 "공유 안 함"으로 보인다.
6. 지도 하단에 OpenStreetMap 출처를 표시한다.

### R9. 모임 장소 정하기
**사용자 스토리:** 멤버로서, 우리가 늘 모이는 장소를 한 번 정해 두고 싶다.

인수 조건
1. 멤버는 지도를 눌러 모임 장소를 지정하고, 반경(50, 100, 200m 중 선택, 기본 100m)을 정한다.
2. 그룹당 하나만 저장된다. 다시 지정하면 덮어쓴다.
3. 바뀌면 그룹의 모든 멤버 화면에 반영된다.
4. 모임 장소가 없으면 자동 출석은 동작하지 않는다.

### R10. 자동 출석
**사용자 스토리:** 모임 장소에 도착하면 따로 누르지 않아도 출석으로 남기고 싶다.

인수 조건
1. 공유 시간대에 정확도가 반경 이하인 위치가 모임 장소 반경 안에 들어오면, 그날 응답이 없는 멤버를 "간다"로 기록한다.
2. 이미 "간다" 또는 "못 간다"로 응답한 멤버는 바꾸지 않는다. "못 간다"는 자동 출석이 덮어쓰지 않는다.
3. 이미 확정된 무응답 차감은 되돌리지 않는다.
4. 자동으로 기록된 응답은 목록에서 "도착"으로 구분해 보인다.
5. 기록되면 R5와 같은 방식으로 그룹 모든 화면에 1초 안에 보인다.
6. 같은 날 두 번 기록하지 않는다.

## 비기능 요구사항
- N6. 지도에 API 키가 필요한 서비스를 쓰지 않는다(OpenStreetMap 타일). 키 없이 clone 후 실행된다. (본 앱 N1과 같은 기준)
- N7. 위치는 DB에 저장하지 않는다. 서버 메모리에만 두고 공유 시간대가 끝나면 지운다.
- N8. 위치 전송은 멤버당 10초에 한 번 이하다.
- N9. 시드와 데모는 가상 좌표만 쓴다. 실제 집 주소를 넣지 않는다.
- N10. 위치 권한은 HTTPS에서만 동작한다. 배포 도메인은 TLS를 쓴다.

## 범위 밖
- 탭이 닫힌 상태의 위치 추적, 백그라운드 지오펜스
- 이동 경로 기록, 도착 예상 시간, 길 안내
- 여러 모임 장소, 요일별 장소
- 위치 이력 저장

## 열린 질문 (임시값)
- 공유 시간대 길이: 알람 후 120분. 상수 `SHARE_WINDOW_MINUTES` 한 곳에 둔다.
- 무응답 확정(10분) 뒤에 도착한 멤버: 차감은 유지하고 응답도 기록하지 않는다(R10.3). 도착을 기록할지는 데모 뒤에 정한다.
- 인증이 없어서 멤버 ID를 아는 사람은 위치를 볼 수 있다. 데모 범위에서는 허용하고 README 한계에 적는다.
