# Design

화면을 만들거나 고칠 때 이 파일을 따른다. 방향은 "밝은 사이버 + 펑크 + 리듬게임". 무겁지 않게, 익살스럽게.

## 방향
- 뮤즈 대시처럼 밝은 파스텔 바탕에 굵은 선, 어긋난 사선, 딱딱한 그림자.
- 셋로그처럼 기록이 카드와 줄로 쌓이는 화면.
- 어두운 터미널, 네온 글로우, 유리 질감은 쓰지 않는다.

## 색 (토큰은 `globals.css`가 단일 출처)
| 이름 | 값 | 쓰임 |
|---|---|---|
| 바탕 | `#e3fff6` | 페이지 배경 |
| 점무늬 | `#b5f0dc` | 배경 점 (12px 간격, 지름 3px) |
| 잉크 | `#0d3b35` | 글자, 선, 그림자 |
| 핑크 | `#ff4fa3` | 주 행동 버튼, 선택 표시 |
| 민트 | `#28d7a8` | 성공, 간다 |
| 노랑 | `#ffe14d` | 강조 버튼, 알람 시간 |
| 경고 | `#ff5a7a` | 못 간다, 무응답, 벌금 |
| 면 | `#ffffff` | 카드, 입력 |
- 한 화면에 핑크 버튼은 하나만.
- 글자는 잉크색. 회색 글자(`gray-400`, `gray-500`)는 쓰지 않는다. 보조 글자는 잉크 70%.

## 글꼴과 크기
- 제목과 숫자: Do Hyeon. 본문: Noto Sans KR.
- 크기는 12, 14, 18, 28, 44px 다섯 개만 쓴다. 알람 시간만 44px.
- 숫자는 `tabular-nums`.

## 모양
- 간격은 4px 배수.
- 모서리는 4px 하나. `rounded-xl` 이상은 쓰지 않는다. 배지만 사선(`skewX(-12deg)`).
- 카드와 버튼은 3px 잉크 선과 `3px 3px 0` 잉크 그림자. 하단 고정 버튼은 `4px 4px 0`.
- 누르면 그림자 없이 2px 아래로 눌린다.
- 알람 시간 블록과 하단 고정 버튼은 `skewX(-8deg)`. 안의 글자는 되돌리지 않는다.
- 흐린 그림자(`blur`), `backdrop-blur`, 그라데이션 배경은 쓰지 않는다.

## 말투
- 짧은 게임 말투. 예: 성공, 놓침, 찌르기.
- 문장마다 줄표(—)를 쓰지 않는다.

## 쓰지 않는 것 (AI 티)
- 보라-파랑 그라데이션, Inter와 Geist, 흐린 유리 질감.
- 같은 아이콘 카드 3개 나란히, 제목 위에 뜬 알약 라벨.
- 모든 요소에 fade-up, 모든 곳에 같은 둥근 모서리와 옅은 그림자.
- 움직임은 기존 파장, 찌르기 흔들림, 연타 배지만. `prefers-reduced-motion`이면 끈다.

## 확인
- 화면을 바꾸면 `visual-check` 절차로 눈으로 확인한 뒤 머지한다.
- 글자와 배경 대비는 4.5:1 이상.
