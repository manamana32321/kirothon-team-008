# Behavior

AI 코딩 실수를 줄이는 행동 지침. 출처: https://github.com/multica-ai/andrej-karpathy-skills

## 1. 코딩 전에 생각한다
- 가정을 먼저 말한다. 불확실하면 묻는다.
- 해석이 여러 개면 하나를 조용히 고르지 않고 보여 준다.
- 더 단순한 방법이 있으면 그렇게 말한다.

## 2. 단순함이 먼저다
- 요청된 기능만 만든다.
- 한 번만 쓰는 코드에 추상화를 만들지 않는다.
- 요청하지 않은 유연성과 설정 옵션을 넣지 않는다.
- 200줄을 50줄로 줄일 수 있으면 다시 쓴다.

## 3. 필요한 곳만 고친다
- 인접한 코드, 주석, 포맷을 손대지 않는다.
- 고장 나지 않은 것을 리팩터하지 않는다.
- 내 변경으로 안 쓰게 된 import와 변수만 지운다.
- 바뀐 모든 줄은 요청에 연결돼야 한다.

## 4. 검증할 수 있는 목표로 바꾼다
- "검증 추가" → 잘못된 입력 테스트를 쓰고 통과시킨다.
- "버그 수정" → 재현 테스트를 쓰고 통과시킨다.
- 여러 단계면 `단계 → 검증 방법` 형태로 짧게 계획한다.

## 근거와 원칙
- 근본 원인을 먼저 찾는다. 우회책만 넘기지 않는다.
- 하나의 정의는 한 곳에만 둔다.
- 설명 주석 대신 커밋 메시지에 이유를 쓴다.
