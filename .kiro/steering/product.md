# Product

## 한 줄
아침 운동 약속을 둔 친구 그룹이, 알람 해제를 곧 참가 선언으로 만들고, 일어나지 않는 친구에게 내 얼굴 영상(카메라를 끄면 목소리)을 알람처럼 보내 깨우는 서비스.



## 대상 사용자
- 평일 아침에 친구와 같이 운동하러 가는 사람
- 약속 시간에 서로 늦잠 자거나 가기 싫어서 미루는 일이 잦은 친구 그룹

## 해결하는 불편
- 지금은 카톡 개인 채팅으로 "ㅇㄷㄱ?"을 치고, 답이 없으면 전화로 깨운다.
- 참가 여부를 모두에게 한 번에 알릴 방법이 없고, 깨우는 방식이 사람마다 다르다.
- 개인 알람은 혼자 끄면 끝이라 약속의 책임이 없다.

## 핵심 기능 (우선순위 순)
1. 운동 그룹 만들기와 초대 코드 참여
2. 그룹별 알람 시간 설정
3. 알람 시간에 알람이 울리고 "간다 / 못 간다" 한 번 누르면 알람이 꺼지고 그룹에 실시간 공유
4. 친구에게 10초 영상을 보내 두면 그 친구의 알람 시간에 반복 재생. 카메라를 끄면 음성만
5. 불참 확정 시 가상 포인트 차감 (장부만, 실제 결제 없음)

## 범위 밖
- 실제 결제와 선금 정산
- 백그라운드 알람 (브라우저 한계. 앱 필요 → 향후 과제)
- 실시간 통화, 계정 인증, 모바일 앱

## 설계 원칙
- 알람 해제 동작 하나가 곧 참가 선언이다. 알람 끄기와 응답을 분리하지 않는다.
- LLM은 쓰지 않는다. 모든 로직은 결정론 코드로 처리한다.
- 같은 정의를 두 곳에 두지 않는다.

## 개인정보
- 레포가 Public이므로 실제 지인 정보와 실제 얼굴·음성을 시드에 넣지 않는다.
- API 키, `.env`는 커밋하지 않는다.
